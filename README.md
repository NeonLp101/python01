# python01

42 Heilbronn — Python module 01: classes, encapsulation and inheritance.

Builds one `Plant` class up across seven exercises, from plain functions to a
class hierarchy with validated attributes and nested bookkeeping.

| | Topic |
|---|---|
| `ex0` | Functions and local variables |
| `ex1` | A first class — `__init__`, attributes, one method |
| `ex2` | Methods that mutate state, driven over a 7-day growth loop |
| `ex3` | Default arguments and a list of instances |
| `ex4` | Encapsulation — `_attributes`, setters that reject negative values |
| `ex5` | Inheritance — `Flower`, `Tree`, `Vegetable`; `super()` in both `__init__` and overridden `show()` |
| `ex6` | A nested `Stats` class tracking how often each method was called |

## Running

```
python3 ex5/ft_plant_types.py
```
